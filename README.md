### 🌳 ArborRoot

**C# фреймворк для создания древовидных сетей устройств с локальным сервером и расширенным управлением файлами**

## 📋 О проекте
**ArborRootHub** - пулть управления, для системы **ArborRoot**.


### 🎯 Основные возможности

| Компонент | Возможности |
|-----------|-------------|
| **🌐 Сетевая архитектура** | Автоматическое построение древовидной сети устройств, P2P-коммуникация, балансировка нагрузки |
| **📁 Файловая система** | Чтение и обработка множества форматов файлов, виртуальная файловая система, кэширование |
| **🎮 Управление устройствами** | Удаленный контроль, ограничение доступа, мониторинг состояния, пакетное управление |
| **🔒 Безопасность** | Шифрование каналов, аутентификация устройств, ролевая модель доступа |

## 🚀 Поддерживаемые форматы файлов (Alfa-1)

| Формат | Статус | Описание |
|--------|--------|----------|
| `.txt`, `.log` | ✅ Реализовано | Текстовые файлы с кодировкой detection |
| `.json` | ✅ Реализовано | JSON-парсер с валидацией |
| `.xml` | ✅ Реализовано | XML-парсер с поддержкой пространств имен |
| `.ini`, `.cfg` | ✅ Реализовано | Конфигурационные файлы |
| `.png`, `.jpg` | 🔄 В разработке | Изображения (метаданные + миниатюры) |
| `.svg` | 🔄 В разработке | Векторная графика |
| `.db` (SQLite) | 🔄 В разработке | Базы данных SQLite |
| `.csv` | 📅 Запланировано | Табличные данные |

##  Поддерживаемые языки для библиотеки

| Язык | Статус | Описание |
|--------|--------|----------|
| `.cpp`, `.h` | ✅ Реализовано | работа с C++ проектами |
| `.java`,`.js` | 🔄 В разработке| работа с Java и JavaScrept |
| `.C`,`.C#` | 🔄 В разработке | Семейсво C |
| `.Pyhton` | 🔄 В разработке | Работа с Питоном |
